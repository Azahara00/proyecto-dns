¿Qué es DNS y para qué sirve?

DNS significa Domain Name System (Sistema de Nombres de Dominio).

Es el sistema que permite relacionar el nombre de una página web con su dirección IP.

Su función es hacer de intermediario: nosotros utilizamos nombres fáciles de recordar y el ordenador obtiene la IP que necesita para localizar el servidor.

💡 Idea clave: DNS funciona como una especie de agenda de Internet: buscas un nombre y obtienes la dirección que le corresponde.
2

¿Por qué usamos nombres como wikipedia.org y no una IP?

Las personas podemos recordar fácilmente nombres como wikipedia.org, pero sería mucho más difícil memorizar las direcciones IP de todas las páginas que visitamos.

Por eso escribimos un nombre de dominio. Después, DNS se encarga de encontrar la IP correspondiente.

¿Qué es la caché DNS y qué significa TTL?

💾 Caché DNS

Es una memoria temporal que guarda respuestas DNS que ya se han consultado.

Así, si volvemos a pedir la misma dirección, puede que el ordenador ya tenga guardada su IP y no necesite hacer toda la consulta otra vez.

⏱️ TTL

TTL significa Time To Live (tiempo de vida).

Indica cuánto tiempo puede mantenerse una respuesta DNS en la caché antes de que tenga que actualizarse o volver a consultarse.

¿Una web puede tener una o varias IP?

Sí, una misma web puede tener varias direcciones IP.

Esto permite, entre otras cosas, repartir las peticiones entre distintos servidores y ayudar a gestionar muchas visitas.

🎯 La respuesta a la pregunta principal

Cuando escribimos una dirección web, DNS busca qué dirección IP corresponde a ese nombre. Primero puede comprobar la caché; si no tiene una respuesta válida, realiza una consulta DNS. Cuando obtiene la IP, el navegador puede contactar con el servidor y cargar la página.

En resumen: nombre web → DNS → IP → servidor → página web.
